Prompts for PDF Studio (Project 1)

=== Prompt 1: Initialize PDF Organiser ===
I want to build a command-line PDF organizer that can merge, split, reorder, rotate, delete, duplicate, extract pages, insert blank pages, and crop PDFs. It must work entirely offline - no uploads, no accounts, no internet required.

Start by reading a sample PDF and listing its pages. Then implement each tool one at a time:
1. Merge: Combine two PDFs into one
2. Split: Extract specific pages from a PDF
3. Reorder: Move pages up/down
4. Rotate: Rotate pages 90 degrees
5. Delete: Remove specific pages
6. Duplicate: Copy a page
7. Extract: Save specific pages as a new PDF
8. Insert blank: Add a blank page
9. Crop: Crop pages to a rectangle

For each feature, first test with a real PDF, then add the next feature in a follow-up prompt. One group at a time works better than one giant prompt.

=== Prompt 2: Implement Merge ===
Build the merge feature: read two PDF files and combine them into one, preserving all pages from both.

=== Prompt 3: Implement Split ===
Build the split feature: read a PDF and extract specific page numbers into a new file.

... continue for all 5 groups (Organise, Edit, Stamp, Convert, Finish)
