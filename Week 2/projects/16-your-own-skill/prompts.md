Prompts for Your Own Skill (Project 16)

=== Prompt 1: Initialize Your Own Skill ===
I want to create one agent skill that works in a brand-new session. Turn repeated long instructions into a short command. Pick one: /viva (asks viva questions from notes, one at a time, then scores you), /resume-roast (checks resume against job post and gives blunt specific fixes), or /one-page-revision (turns a chapter into a one-page revision sheet.

=== Prompt 2: Do the Task Once in Chat ===
Perform the chosen task (viva, resume roast, or one-page revision) in regular chat until the result is good and satisfactory.

=== Prompt 3: Turn Conversation into a Skill ===
Ask your agent to turn that conversation into a skill. Write the description clearly, because it decides when the skill runs. The skill description should be specific enough that it triggers at the right time.

=== Prompt 4: Test Skill Starts Correctly in Fresh Session ===
Start a new chat session and invoke the skill. Verify it starts correctly and works as expected.

=== Prompt 5: Test on 3 Different Inputs ===
Try the skill on 3 different inputs or scenarios. It should work well on each.

=== Prompt 6: Compare Without Skill ===
Run the same task without the skill. Show what got better with the skill enabled.

=== Prompt 7: Ensure Skill Description Is Clear ===
The skill description should clearly describe when it should run (what inputs, what task).
