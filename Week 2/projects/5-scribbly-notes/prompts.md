Prompts for Scribbly Notes (Project 5)

=== Prompt 1: Initialize Scribbly Notes ===
I want to build an app that turns typed notes into pretty hand-drawn notebook pages. It needs 1 text box with a live notebook page preview, 3 handwriting styles, 3 ink colours, 2 paper styles, natural variation so lines don't look machine-made, long notes flowing onto new pages, and save as images or PDF. All fonts stored in the project so it works with Wi-Fi off.

Start with one handwriting font on lined paper. Then vary each word's position, size and angle slightly. Keep the font files inside your project.

=== Prompt 2: Implement Text Box with Live Preview ===
Create a textarea where users type notes. Show a live preview of how it will look on lined notebook paper below the text box.

=== Prompt 3: Implement 3 Handwriting Styles ===
Add 3 different handwriting font styles. Each should have natural variation - slightly different position, size and angle for each character so it doesn't look machine-printed.

=== Prompt 4: Implement 3 Ink Colours ===
Add 3 ink colours (e.g., blue, black, red) for the handwritten text.

=== Prompt 5: Implement 2 Paper Styles ===
Add 2 different paper styles (e.g., wide-ruled and college-ruled with different line spacing).

=== Prompt 6: Implement Natural Variation ===
For each word or character, add slight random variations to position (x,y), font size, and slant/angle. This makes it look genuinely handwritten rather than computer-generated.

=== Prompt 7: Implement Multi-Page Support ===
When notes are long, automatically flow them onto new pages. Each new page should continue from where the last one left off.

=== Prompt 8: Implement Save as Image ===
Add a "Save image" button that exports the current page as a PNG or JPEG.

=== Prompt 9: Implement Save as PDF ===
Add the ability to save all pages as a single PDF file.

=== Prompt 10: Store Font Files in Project ===
Ensure all handwriting font files (.ttf or .woff) are stored within the project folder so the app works offline with Wi-Fi off.

=== Prompt 11: Test Friend Readability ===
Ask a friend to read a sample page. The handwriting should be pleasant to read, not too messy.

=== Prompt 12: Test 3-Page Note Split ===
Test that a 3-page note splits correctly with no line cut in half between pages.
