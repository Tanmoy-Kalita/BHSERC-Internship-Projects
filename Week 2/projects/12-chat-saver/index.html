AI Assistant:

Retrieval-Augmented Generation (RAG) combines semantic vector search with LLM reasoning. Here is the architecture:

StageFunctionLatency
EmbeddingConvert query to dense vector~20ms
Vector IndexRetrieve top-K chunks via cosine similarity~10ms
GenerationInject retrieved context into prompt~300ms
def retrieve(query, top_k=3):
    query_vector = embed_model.get_vector(query)
    results = vector_index.search(query_vector, top_k)
    return [match['text'] for match in results]
