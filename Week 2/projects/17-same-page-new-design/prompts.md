Prompts for Same Page, New Design (Project 17)

=== Prompt 1: Initialize Same Page, New Design ===
I want to build a plain page without design skills, then redesign it with one. The words stay the same. Step 1: build a simple page for a college fest, cafe, coaching institute or own idea using no design skill. Save as before.html. Step 2: install Impeccable skill (or browse skills.sh for others like frontend-design or ui-uxpro-max). Step 3: redesign using the skill on the same page. Save as after.html. Both files must have matching text, redesign works on a phone, can name 3 design changes and why each helps.

=== Prompt 2: Build Before Page (No Design Skill) ===
Create a simple HTML page for a college fest with the text content from the project description. No special styling, just basic structure. Save as before.html.

Content to include:
- TECHNOVA 2026
- Three days of robotics, code and music
- Register now
- Robotics, Hackathon, Music night
- Chai and Co. with food items and prices

=== Prompt 3: Install and Use Design Skill ===
Install the Impeccable skill (or similar frontend-design/ui-uxpro-max skill). Apply it to the same page content to create a beautifully designed version. Save as after.html.

=== Prompt 4: Verify Text Matches Between Pages ===
Compare before.html and after.html. Ensure all the same text content is present in both files.

=== Prompt 5: Test Responsiveness on Phone ===
View both pages on a phone/mobile browser. The redesign should work well on mobile.

=== Prompt 6: Name 3 Design Changes and Benefits ===
Identify 3 design changes made from before to after, and explain why each one helps (e.g., better readability, improved visual hierarchy, more engaging layout).

=== Prompt 7: Bonus - Try Second Design Skill ===
Try a second design skill from skills.sh on the same page and compare the results.
