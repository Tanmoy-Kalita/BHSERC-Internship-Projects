Prompts for Auto Rally (Project 8)

=== Prompt 1: Initialize Auto Rally ===
I want to build a cute auto-rickshaw racing game that friends can play on their phones. Must work in flight mode. Features: driveable auto-rickshaw on looping road, keyboard and touch controls, coins, obstacles, at least one power-up, 3 laps with timer, best time saved, sound with mute button.

Start with auto moving on a straight road on HTML canvas. Then add steering, then coins and obstacles, then laps. Play it after every step.

=== Prompt 2: Implement Auto-Rickshaw Movement ===
Create an HTML canvas game where the auto-rickshaw moves forward automatically on a looping road background. Use keyboard (arrow keys) and touch controls.

=== Prompt 3: Implement Steering Controls ===
Add steering functionality: left/right movement, turning the auto-rickshaw on the road. Keep it on the road and prevent falling off.

=== Prompt 4: Implement Coins and Obstacles ===
Add coins to collect and obstacles to avoid. Coins should increase score; obstacles should end game or cause penalty.

=== Prompt 5: Implement Power-Up ===
Add at least one power-up (e.g., speed boost, invincibility) that the auto-rickshaw can collect.

=== Prompt 6: Implement 3 Laps with Timer ===
Add a 3-lap race with a timer. Complete 3 laps within time limit or beat your best time.

=== Prompt 7: Implement Best Time Saving ===
Save the best completion time. This should survive a restart of the game.

=== Prompt 8: Implement Sound and Mute Button ===
Add sound effects (engine, coin collection, crash) and a mute button to toggle sound on/off.

=== Prompt 9: Test in Flight Mode ===
Verify the game works completely in flight mode - no internet required.

=== Prompt 10: Test Friend Can Play ===
Have a friend play a full race with no instructions from you. Verify crashes and lap counts feel fair.
